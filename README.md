# 三轮车驾考模拟 · D 照

三轮摩托车 D 照驾考模拟桌面程序，覆盖**理论考试**（科目一 / 科目四）与**实操考试**（科目二 / 科目三）两条完整链路：题库练习、模拟考试计时判分、实操项目逐步引导与评判、成绩单反馈。

界面与信息架构沿用既有原型设计稿，工程上按主流方案重新组织为可运行、可维护的桌面应用。

## 技术方案

| 层次   | 选型                                                     |
| ---- | ------------------------------------------------------ |
| 桌面容器 | Electron 33（主进程 `electron/main.js`）                    |
| 前端框架 | Vue 3（`<script setup>` + TypeScript）                   |
| 状态管理 | Pinia（单 store，含 localStorage 持久化）                      |
| 路由   | Vue Router 4（hash 模式，兼容 `file://` 加载）                  |
| 构建   | Vite 5                                                 |
| 类型检查 | vue-tsc                                                |
| 题库采集 | Node 侧采集器（`electron/collector`）+ sql.js 解析官方 SQLite 题库 |

## 运行说明

```bash
# 1. 安装依赖（首次执行）
npm install

# 2. 启动桌面程序（推荐）
npm start          # 先构建前端产物，再打开桌面窗口
# 首次启动后，进入侧栏「数据采集」点「立即采集」即可把线上数据采集到本机 data/ 目录：
# 科目一 1484 题 / 科目四 409 题（含各省地方题 669 题与 243 张题图），
# 以及 151 个线上教学视频目录与 39 篇线上图文目录，耗时约 10 秒～1 分钟（视网速）。

# 3. 开发模式（前端热更新 + 桌面窗口）
npm run dev

# 4. 仅浏览器运行（不启动 Electron）
npm run web        # 打开 http://127.0.0.1:5173
```

其他脚本：

```bash
npm run build       # 类型检查 + 构建到 dist/
npm run build:only  # 仅构建，不做类型检查
npm run typecheck   # 仅类型检查
npm run desktop     # 直接用已构建产物启动桌面窗口（需先 build）

# 题库采集（脱离桌面端独立运行，便于测试或接入系统计划任务）
npm run collect              # 立即采集一次
npm run collect:status       # 查看采集配置、题库统计与数据文件
npm run collect:clear-cache  # 清理原始下载缓存（下次采集重新下载）
```

> 若 `npm install` 卡在 Electron 运行时二进制下载（默认从 GitHub 拉取约 100MB），
>
> 可先设置国内镜像后重试：
>
> ```powershell
> $env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"; npm install
> ```

## 功能清单

### 理论考试

- **学习总览**：继续上次练习、备考路线、章节掌握度、错题与题库状态。
- **题库练习**：顺序 / 随机 / 章节 / 错题本 / 收藏夹五种模式；单选点击即判定，多选需确认；答错自动进错题本，可收藏、重做本轮，支持键盘作答。
- **模拟考试**：按考试规则随机抽题（D 照科目一 / 科目四均为 50 题，每题 2 分，90 分及格）、限时倒计时（45 / 30 分钟）、答题卡跳转与疑问标记、到时自动交卷、交卷确认、成绩单（得分、合格判定、答对/答错/未答/用时）与逐题错题解析。

### 数据采集与题库更新（第 8 项）

从线上公开数据源采集题目、插图、地区题库与线上图文 / 视频教程目录，保存在项目目录 `data/` 下（该目录已加入 `.gitignore`，不入版本库），与内置题库自动去重合并。当前示例采集结果：**科目一 1484 题 + 科目四 409 题**（其中各省地方题 669 题、题图 243 张）、**视频目录 151 条 + 图文目录 39 条**。

- **手动采集**：数据采集页点「立即采集」（可对单个数据源点「单独采集」）；也可在应用「采集」菜单触发，或用 `npm run collect` 命令行执行。
- **定时采集**：可开关并按小时配置间隔（默认 24 小时），应用运行期间由主进程调度，界面展示上次/下次采集时间与上次结果；也可用系统计划任务调用 `npm run collect` 实现开机自动更新。
- **增量与缓存**：通过远端 commit 指纹判断题库是否更新，未更新则复用本机缓存不重复下载；合并按题干指纹去重，重复采集结果幂等。
- **数据源（7 个默认启用）**：
  1. 驾考宝典 · 摩托车全量题库（`jiakao-sqlite`）：官方 SQLite 题库，字段 XOR 解密，含答案位掩码、交通标志插图与各省地方题库。
  2. 元贝驾考 · 开车技巧图文（`html-list`）、元贝驾考 · 学车视频目录 / 科目二视频 / 科目三视频（`html-list`）。
  3. 驾考宝典 · 科目二 / 科目三项目讲解（`html-list`，含真实视频时长）。  
     另有 3 个可配置数据源：自定义图文列表页、自定义 JSON 题库接口（含字段映射）、自定义视频目录接口。
- **列表页解析规则**：每个 `html-list` 源配置 `url` / `base` / `hrefPattern`（链接正则）/ `minTitleLen`·`maxTitleLen`（标题长度区间）/ `dur`（是否提取时长）等，只读取公开列表页上的**标题、原文链接与时长**，不抓取正文、不绕过任何鉴权。
- **数据管理**：本地题库文件导入（JSON / CSV，追加或覆盖）、当前题库导出、清理原始下载缓存、清空采集题库、打开数据目录。
- **降级策略**：未采集或采集失败时自动使用内置题库与内置教程目录，功能不受影响；浏览器模式下采集页只读展示采集状态（开发期由 Vite 中间件提供只读数据桥）。
- **与做题 / 考试打通**：采集题库自动进入练习与考试。合并时**采集题库排在前面**，顺序练习、章节练习优先出采集题；题目卡片右上角标注来源标签（采集题库 / 内置题库），练习侧栏显示「本轮题库 内置 x + 采集 y」；模拟考试按考试规则从合并题库中随机抽 50 题。题库变化（首次装载、采集完成、切换地区、导入、清空）后练习轮次会自动按最新题库重建。
- **地区题库真正生效**：采集时按章节标题识别省份写入题目的 `area` 字段（未标注省份的记为「通用」）；渲染层按「全国通用题 + 当前省份地方题」重建可用题库，**切换地区后题量立即变化**（例如重庆 148+23 题、山东 21+23 题）。同一题属于多个地方题库时保留全部归属。
- **网络容错**：题库下载地址支持多镜像按顺序回退并自动重试（jsDelivr → ghproxy → raw.githubusercontent）；列表页请求失败只影响该数据源，不阻断整体采集。

### 实操考试

- **科目二 · 场地驾驶**：桩考、坡道定点停车与起步、通过单边桥、直角转弯（12 个评判步骤）。
- **科目三 · 道路驾驶**：上车准备与起步、直线行驶与变更车道、通过路口与人行横道、掉头与靠边停车（12 个评判步骤）。
- **完整流程**：选择科目 → 流程条展示当前进度 → 逐步给出语音播报指令与操作引导 → 对每一步选择评判结论（规范操作 / 扣分 / 不合格）→ 可撤销上一步 → 提交生成成绩单。
- **完整操作路径**：开始、暂停（计时停止）/ 继续、撤销上一步、重新考试（含二次确认）、提交试卷。
- **评判与反馈**：满分 100 分、80 分及格；扣分项按标准累计，出现不合格情形则本次判定不合格、成绩记 0 分；成绩单含各项目得分表、扣分明细、不合格项清单与全部评判记录。
- **项目讲解资源**：把采集到的线上图文与视频按项目关键词（桩考 / 倒车入库、坡道、单边桥、直角转弯、变更车道、靠边停车……）关联到每个实操项目；待考页展示「项目讲解资源」清单，考试中当前项目侧栏给出「相关讲解」，点击在系统浏览器打开原文。

### 资料与数据

- **图文 / 视频教程**：内置 8 篇图文分解（含步骤示意图、操作步骤、要点提示、已读标记）与 6 段视频课程目录；下方另设「线上采集课程」与「线上图文教程」分区，展示采集到的标题、时长、分类与来源，点击跳转原文页面。
- **安全驾驶专栏**：6 篇文章，按日常使用 / 安全驾驶 / 法规常识分类。
- **题库与地区**：31 个省级行政区切换（按钮显示各省已采集地方题量）、题库构成（内置 / 采集 / 其中地方题 / 合计）、地方题库分布、题库健康度（总量 / 采集占比 / 配图 / 解析覆盖）、章节题目分布、采集题库状态、更新日志、本机学习档案、载入演示档案 / 清空错题本 / 重置记录。
- **数据采集**：采集源启停、手动与定时采集、进度日志、线上教程目录统计、题库文件清单、采集题库抽样预览、导入 / 导出 / 清空 / 打开数据目录。

### 通用

- 科目一 / 科目四随时切换；若当前有进行中的模拟考试，会先弹窗确认，避免已作答内容被直接丢弃。
- 学习记录保存在本机 localStorage，无需登录；仅「数据采集」功能需要联网，未联网时自动使用内置题库与内置教程目录。
- 响应式布局，窄屏自动切换为底部导航。

## 说明

- 内置题库与评判项依据现行《道路交通安全法》及配套规定、《机动车驾驶人考试内容和方法》整理，示例为省级题库节选与常见评判标准；正式考试以当地车管所公布的项目、题库范围与评判标准为准。
- 采集数据来自线上公开数据源（官方客户端公开题库、公开仓库镜像、公开列表页），**仅供个人学习研究使用**，请遵守来源站点的使用条款，不要用于商业用途或对外分发原始数据。
- 线上图文与视频目录**只采集公开列表页上的标题、原文链接与时长**，不抓取正文、不绕过任何登录或签名校验；点击后跳转到来源站点阅读 / 观看。官方讲解视频接口需要 URL 签名，程序不做破解，因此不提供可播放的视频文件。
- 采集题库中的解析与法规依据来自数据源原文，未经逐条人工复核，仅作学习参考。
- 地方题库按章节标题归属省份：标题中不含省份名的归入「通用」，对所有地区可见；若某道地方题与全国通用题题干相同，合并后按全国通用题处理。
- 成绩仅用于自测，不代表正式考试结果。
